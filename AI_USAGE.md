# AI Usage

## Overview

AI tools were used as development assistance during this project.

The primary AI tool used was ChatGPT.

AI was used as a productivity and learning tool. The generated suggestions were reviewed, modified where necessary, and tested during implementation.

---

## Usage

| Tool    | What I Used It For                       | Why I Used AI                                          | What I Personally Verified                                    |
| ------- | ---------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| ChatGPT | React component structure                | To speed up frontend development                       | Tested the components and UI manually                         |
| ChatGPT | Express REST API structure               | To understand and implement backend endpoints faster   | Tested API requests and responses                             |
| ChatGPT | MongoDB/Mongoose implementation guidance | To understand database operations and schema structure | Verified database records and API behavior                    |
| ChatGPT | Debugging frontend/backend issues        | To identify possible causes of errors                  | Reproduced and tested the fixes locally                       |
| ChatGPT | Code explanations                        | To understand unfamiliar implementation details        | Reviewed the code and confirmed how it works                  |
| ChatGPT | Business insight implementation guidance | To structure calculations                              | Verified the calculations against the supplied dataset        |
| ChatGPT | Data-quality handling guidance           | To identify appropriate handling approaches            | Reviewed the supplied data and verified the identified issues |

---

## How AI Was Used

AI assistance was mainly used for:

* Explaining React and Express concepts
* Structuring components
* Creating and debugging REST API logic
* Understanding MongoDB/Mongoose operations
* Debugging implementation issues
* Improving code organization
* Explaining implementation decisions
* Structuring documentation

---

## What Was Personally Verified

I personally:

* Ran the frontend locally.
* Ran the backend locally.
* Connected the application to MongoDB.
* Seeded the supplied CSV data.
* Tested the REST APIs.
* Tested search and filters.
* Tested sorting and pagination.
* Tested application details.
* Tested status updates.
* Tested creating a new application.
* Verified that dashboard values update from database data.
* Reviewed the business insight calculations.
* Reviewed the identified data-quality issues.

---

## Business Insights

AI was not used to fabricate business insights.

The insights shown in the dashboard were calculated from the supplied synthetic dataset.

The calculations were reviewed against the underlying application data.

---

## AI Limitations

AI-generated suggestions were not blindly accepted.

Where AI provided code or implementation suggestions, the code was reviewed, integrated and tested locally.

The final implementation was checked to ensure that I understand the functionality and can explain the main technical decisions and debugging steps.
